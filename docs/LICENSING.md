# Licensing decision

This release uses the unmodified Mozilla Public License 2.0 for the public demo and its accompanying materials. See LICENSE for the controlling text.

| Option considered | Fit for this release |
| --- | --- |
| MIT / Apache-2.0 | Easy reuse, but do not require distributed changes to remain available as source in the way MPL does. Not selected. |
| MPL-2.0 | Commercial reuse plus file-level copyleft; a useful boundary around a small public prototype. Selected. |
| AGPL-3.0 | Stronger sharing requirements, including certain network uses; a broader commitment than this small demonstrator needs. Not selected. |
| All rights reserved / custom noncommercial terms | More restrictive reuse, but less suitable for a runnable community prototype; noncommercial terms are not open source. Not selected. |

MPL allows third-party commercial use. It does not prevent competing implementations. Covered-file distribution obligations do not automatically extend to independent proprietary files, and running a modified server alone is not generally distribution under MPL. The license contains a contributor patent grant within its defined scope; it is not a blanket reservation of every possible patent claim.

Private ELFCORE code is not included. This release does not change licenses on other repositories. Publication can disclose ideas, regardless of license; this document makes no novelty or patentability claim. Future separately authored commercial components may have separate terms, while already granted rights to this public release remain governed by MPL. Contributions retain their authorship; no copyright assignment or promise of unilateral relicensing is requested.

Sources: [Mozilla MPL FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/), [MPL text](https://www.mozilla.org/en-US/MPL/2.0/), [GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
