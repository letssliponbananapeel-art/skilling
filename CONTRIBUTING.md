# Contributing

Start with a small reproducible example or a clear counterexample. Useful contributions include synthetic event fixtures, better outcome definitions, accessibility and translation improvements, and tests of where preference and skill can be confused.

1. Open an issue describing the problem, expected behavior and an anonymized or synthetic example.
2. Keep changes scoped to the public prototype. Never include private ELFCORE code, credentials, personal conversation logs or unconsented user assessments.
3. Run `python3 -m unittest discover -s tests -v` and `python3 demo.py --decision register`.
4. Submit a pull request explaining the behavior change and evidence. Maintain both READMEs when changing the concept.

Contributions are offered under this repository's MPL-2.0 license. Retain attribution and license notices. No copyright assignment is requested. Be respectful; challenge claims and mechanisms, not people. Do not submit fabricated benchmark results or exchange/purchase stars.
